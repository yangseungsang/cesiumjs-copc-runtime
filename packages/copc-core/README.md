# cesiumjs-copc-core

Core COPC loading package for
[CesiumJS COPC Runtime](https://github.com/yangseungsang/cesiumjs-copc-runtime).

Provides `CopcSource`, hierarchy traversal, coalesced byte-range reads, memory and
IndexedDB caches, decode types, node identifiers, and point filtering. It has no
CesiumJS dependency and can support rendering or source-CRS analysis clients.

See the [architecture](https://github.com/yangseungsang/cesiumjs-copc-runtime/blob/main/docs/architecture.md)
and [API reference](https://github.com/yangseungsang/cesiumjs-copc-runtime/blob/main/docs/api-reference.md).
